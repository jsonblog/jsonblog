# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be respectful, assume good faith, and help keep this a welcoming space
for everyone. Unacceptable behavior can be reported to the maintainers, who will
review and act on it. Maintainers may remove, edit, or reject contributions and
comments that don't align with this Code of Conduct.
